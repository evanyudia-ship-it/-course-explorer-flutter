# Course Explorer - Flutter Pertemuan 5

Project ini mengikuti spesifikasi mini project Responsive Course Explorer pada worksheet.

## Fitur
- Responsive layout dengan LayoutBuilder
- Breakpoint compact / medium / expanded
- GridView responsif
- NavigationBar untuk layar compact/medium
- NavigationRail untuk layar expanded
- Navigator.push() dan Navigator.pop(result)
- Passing data course melalui constructor
- Favorite/interaksi
- SnackBar dan Dialog
- Form + TextFormField + validasi
- SingleChildScrollView
- 5 data course

## Sebelum dijalankan
Buka `lib/main.dart`, lalu ganti:
- `studentName`
- `studentId`

## Menjalankan
```bash
flutter pub get
flutter run
```
